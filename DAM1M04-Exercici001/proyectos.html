Aprendiendo a programar

Estoy haciendo diferentes proyectos para aprender a programar como por ejemplo:

  • Tres en raya en Python
  • Tetris en Python
  • Pagina web personal HTML
     

Pasos a seguir para desarrollar un proyecto

  1. Determinar que quieres que haga el programa o la pagina web antes de escribir el codigo.
  2. Elegir cual va a ser el lenguaje que vas a usar para el proyecto.
  3. Ir construyendo el proyecto paso a paso, empezando por las funciones más sencillas.
  4. Probar y corregir erorres.
  5. Publicar el codigo en github.
